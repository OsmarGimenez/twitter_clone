# Primera version del clon de Twitter
#### Pasos a seguir para configurar / levantar el proyecto:

1. Descarga el siguiente repositoria como zip  preferentemente en el escritorio.

```git clone https://github.com/OsmarGimenez/twitter_clone```

2. Crea un ambiente virtual 

```python -m venv socialenv```


3. Instala las dependencias/librerias en requirements.txt

```pip install -r requirements.txt```


4. Ejecuta las migraciones.

```python manage.py makemigrations```
```python manage.py migrate```


5. Crea un superusuario.

```python manage.py createsuperuser```

6. Corre el servidor.

```python manage.py runserver```
